# Examples

- `mcp_client.py`: an example MCP client. A language model (any entry of `configs/models.json`) carries out one task through
  the MCP server; `--dry_run` uses a scripted model and needs no API key. See the README, "One task with an MCP client as the
  agent".

Example runs (log.json, report.md, videos) will be added here.
